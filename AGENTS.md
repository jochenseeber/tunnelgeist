# Agent instructions

Building, testing, the gates before committing, the commit rules and the code
conventions are in `docs/CONTRIBUTING.md`; follow them. In addition:

- Use the `my:development` and `superpowers` skills.
- Use the `my:development-crystal` skill for Crystal development.
- Use the `my:development-ruby` skill for Ruby development.
- Agents commit their own work, one commit per concern.
- Nothing is pushed without approval.
